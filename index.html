              没有服务时，怎么手动更新？

              更新按钮需要一个在后台运行的小服务，它负责调用抓取脚本。没有服务时按下面任一种方式处理，完成后刷新本页即可看到新数据。

              方式一　启动本地更新服务（推荐，双击后一步到位）

              双击 tools\启动更新服务.bat：服务启动后会自动在浏览器里打开本页，之后「立即更新行情数据」随时可用。也可以在本文件夹下打开命令提示符或终端，手动执行：

              python tools/update-server.py

              方式二　只跑一次抓取脚本

              python tools/fetch-market-data.py

              也可以双击 tools\更新行情.bat。脚本把结果写入 market-data.js，完成后刷新本页。

              方式三　每个交易日自动更新

              连上服务后直接点上面的「开启每个交易日自动更新」即可，无需手动配置任务计划。手动配置步骤与接收方准备清单见随文件夹一起提供的 数据更新说明.md。
